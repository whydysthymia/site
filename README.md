# Сайт-визитка Ивана Манылова

Одностраничная визитка на HTML5, CSS3 и vanilla JavaScript. Без фреймворков.

Откройте `index.html` в браузере. Если скрипты ведут себя странно, достаточно любого статического сервера, например: `python3 -m http.server 8080`.

## Инструменты и задачи

| Инструмент | Задача |
| --- | --- |
| ChatGPT | Формулировка исходного промпта: бриф, ТЗ, требования к вёрстке, доступности и этапам работы |
| Cursor | Интервью по брифу, сборка ТЗ, HTML/CSS/JS, адаптив, тема, язык, форма, README |

Нейросеть, с которой собирался код: **Cursor Grok**.

Время работы над кодом: **18.09.2026, около 50 минут** (после утверждения ТЗ).

## Существенный запрос и проверка

**Запрос к Cursor:** собрать одностраничный сайт по утверждённому ТЗ: Mobile First, RU/EN, светлая и тёмная тема, без градиентов, рамок и кастомного курсора; Hero на CSS-геометрии; 4 карточки портфолио с цветными плейсхолдерами; форма без бэкенда; в подвале — инструменты, время, список JS; подробности — в README.

**Проверка:** страница открывается, якоря ведут к секциям, RU/EN меняет тексты и `lang`, тема переключается и переживает перезагрузку, мобильное меню открывается и закрывается, форма без валидных полей показывает ошибку, с валидными — модальное окно. На узкой ширине нет горизонтального скролла, фокус клавиатуры виден.

## Что реализовано на JavaScript

- светлая / тёмная тема и сохранение в `localStorage`
- язык RU / EN и сохранение в `localStorage`
- мобильное меню, Escape, закрытие по якорю
- плавный скролл к секциям
- появление блоков при скролле (reveal), с учётом `prefers-reduced-motion`
- проверка полей формы и имитация отправки
- модальное окно подтверждения

## Исправления студента

Самостоятельные решения до генерации кода (не предложены моделью как единственный вариант, а заданы студентом):

- позиционирование как frontend, не fullstack
- обязательные светлая и тёмная темы
- оба языка сразу
- без хостинга и без SEO-оптимизации
- тексты пишет ИИ, контакты и недостающие факты — заглушки
- микс минимализма, editorial-типографики и более дерзкого контраста
- без градиентов, рамок и нестандартного курсора
- геометрия на CSS вместо фото; навыки без иконок
- в подвале: какой инструмент для какой задачи, время, JS-функционал
- исходный промпт — ChatGPT, код — Cursor
